## 🚀 Hướng Dẫn Mở & Triển Khai

1. **Xem trực tiếp trên máy tính:**
   - Chỉ cần nhấp đúp vào file `index.html` để mở ngay trên trình duyệt Google Chrome, Microsoft Edge, Cốc Cốc hoặc Safari.
2. **Đưa lên Hosting/Tên miền riêng:**
   - Bạn có thể tải toàn bộ thư mục này lên bất kỳ dịch vụ lưu trữ nào (cPanel, Hostinger, Vercel, Netlify, Cloudflare Pages, GitHub Pages,...) mà không cần cài đặt thêm bất kỳ thư viện nào.
3. **Tích hợp Google Sheets / Webhook:**
   - Trong file `script.js` tại hàm `handleFormSubmit()`, bạn có thể thêm đoạn mã gửi dữ liệu (Fetch/Axios) về Google Sheet hoặc CRM bán hàng cực kỳ dễ dàng.
